## 🚀 Featured Project
### 🔴 HAPP:ME - 청년 정책·혜택 맞춤 추천 서비스 (2026.06.10 ~ 2026.08.04)
**프로젝트 한 줄 소개**: 청년들이 자신에게 맞는 정책·혜택을 쉽게 찾지 못하는 문제를 해결하기 위해, 이미지 속 정책 정보를 AI가 인식·요약하고 사용자 프로필에 맞춰 신청 가능한 정책과 미래 시나리오별 정책을 추천해주는 서비스입니다.

- 이미지 탐지 파이프라인 구축 및 파인튜닝: Faster R-CNN과 YOLOv11을 활용해 2단계 객체 탐지 파이프라인을 설계하고, 직접 라벨링한 데이터셋으로 파인튜닝하여 정책 이미지 속 텍스트 영역을 정확히 탐지
- OCR·임베딩 매칭 및 LLM 정책 판정 로직: PaddleOCR로 텍스트를 추출하고 SBERT 임베딩 기반 유사도 매칭으로 관련 정책을 찾은 뒤, watsonx.ai LLM으로 최종 정책 요약 및 판정을 수행하는 4단계 AI 파이프라인 구현
- AWS 인프라 배포 및 CI/CD 자동화: 프론트엔드(S3+CloudFront), 백엔드(ECS Fargate+ALB+RDS), AI 서버(EC2 GPU 인스턴스)로 구성된 전체 프로덕션 인프라를 설계·배포하고, GitHub Actions로 세 저장소의 CI/CD 파이프라인을 구축
- 소셜 로그인 및 인증 시스템 구현: Google·Kakao·Naver 소셜 로그인과 이메일 인증을 지원하는 httpOnly 쿠키 기반 JWT 인증 시스템을 구현하고, 제공자별 계정을 분리 관리
- 청년 실태조사 군집분석 시장조사: 2024 청년삶실태조사 마이크로데이터를 활용한 K-means 군집분석으로 청년 유형을 도출하고, 이를 근거로 서비스의 핵심 기능 방향을 설계
